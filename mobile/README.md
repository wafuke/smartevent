# SmartEvent Mobile — React Native Expo Application

The official React Native mobile application for Strathmore University students to browse campus events, register/RSVP, and receive Priority-Based SMS alerts.

---

## How to Run the Mobile App

### 1. Install Dependencies
```bash
cd mobile
npm install
```

### 2. Start Expo Development Server
```bash
npm start
# or
npx expo start
```

### 3. Preview Options:
- **On Physical Smartphone**: Download the **Expo Go** app from App Store (iOS) or Play Store (Android) and scan the QR code displayed in your terminal.
- **On Web Browser**: Press `w` in the terminal to launch the web preview.
- **On Android Emulator**: Press `a` (requires Android Studio).
- **On iOS Simulator**: Press `i` (requires Xcode on macOS).
