HOW TO OPEN TERMINALS IN VS CODE:
---------------------------------
1. Press Ctrl + ~ (or click Terminal -> New Terminal).
2. Click the '+' button in the top-right corner of the terminal panel to open
   separate terminal tabs for each service below.

--------------------------------------------------------------------------------
TERMINAL 1: NODE.JS BACKEND REST API & PRIORITY SMS ENGINE (PORT 5000)
--------------------------------------------------------------------------------
Commands to run:
  cd backend
  npm install
  npm start
  (or: npm run dev)

Run automated backend test suite (19 tests):
  cd backend
  npm test

Access Points:
  - Backend Root / API Gateway: http://localhost:5000
  - API Health & DB Metrics:    http://localhost:5000/api/health
  - Full Database Inspection:   http://localhost:5000/api/db
  - Events API:                 http://localhost:5000/api/events
  - Student RSVPs API:          http://localhost:5000/api/registrations
  - Priority SMS Status API:    http://localhost:5000/api/sms/status
  - Priority SMS Logs API:      http://localhost:5000/api/sms/logs

--------------------------------------------------------------------------------
TERMINAL 2: PYTHON FASTAPI MACHINE LEARNING ENGINE (PORT 8000)
--------------------------------------------------------------------------------
Commands to run:
  cd ml-service
  pip install -r requirements.txt
  python train_model.py
  python main.py

Note: Even if Terminal 2 is not running, the Node.js backend includes a built-in
trained Scikit-Learn Logistic Regression fallback engine (/api/ml/predict and
/api/ml/metrics) so ML predictions and model diagnostics always work offline.

Access Points:
  - ML Prediction API Health:   http://localhost:8000/health
  - Interactive Swagger Docs:   http://localhost:8000/docs
  - ML Prediction Endpoint:     POST http://localhost:8000/predict
  - Backend ML Metrics Proxy:   http://localhost:5000/api/ml/metrics

--------------------------------------------------------------------------------

AFRICA'S TALKING SMS GATEWAY (OPTION A SANDBOX vs. OPTION B LIVE CARRIER SMS)
--------------------------------------------------------------------------------
- Pre-configured in backend/.env with Africa's Talking API Key.
- Option A (Sandbox / Simulation Mode):
    Uses AT_USERNAME=sandbox. Dispatches to the Africa's Talking Sandbox Simulator
    and logs delivery receipts without requiring airtime.
- Option B (Live Carrier SMS to Real Phone Numbers):
    1. Log in as Super Admin (elvis.wafuke@strathmore.edu) or Organizer.
    2. Open the Priority SMS Engine panel and click "Configure Option B (Live SMS)".
    3. Enter your Live App Username from https://account.africastalking.com
       (not "sandbox") and your API Key, then click "Save & Activate Gateway".
    4. Alternatively, update AT_USERNAME in backend/.env to your live username.
    5. Use "Direct Live / Test SMS to Any Phone Number" to send an instant SMS
       to any Kenyan phone number (+2547XXXXXXXX or 07XXXXXXXX).
